# DaysEngine for Android

DaysEngine 的非官方 Android 版本。本仓库用于免费发布安装包、更新说明和接收问题反馈，不包含 App 源代码。

让 School Days HQ、Shiny Days 和 Cross Days 在 Android 手机和平板上运行：读取你自己的游戏目录，使用游戏自带的界面，并加入触屏操作、双语字幕、内置路线攻略与好感度提示、存档备份等功能。

## 安装与使用

- Android 7.0 或更高版本；当前安装包支持 ARM64 设备。
- 本应用不附带游戏本体或游戏资源。须自行准备合法取得且依法允许使用的完整游戏安装目录。
- 安装 APK 后阅读用户协议，通过系统文件夹选择器添加游戏目录。
- 软件主要用于 School Days HQ、Shiny Days 和 Cross Days；兼容性取决于游戏版本和设备。
- 仅限年满 18 周岁且达到所在地法定成年年龄的用户使用；所运行内容和使用方式还须符合所在地法律。

**从旧调试签名版本首次升级到 0.3.0：先导出存档，再卸载旧版、安装新版，然后重新添加目录并导入存档。** 后续同一正式签名版本可以覆盖更新。
